# Сайт приюта «Добрые лапы»

Учебный проект. Верстаю главную страницу по макету из Figma.

## Что готово

- шапка с логотипом и меню
- первый экран с заголовком и кнопками
- блок с цифрами приюта
- карточки питомцев (3 из 4)

## Что осталось

## Как посмотреть
